One-time setup

  1. Go to the Google Cloud Console and create a new project (or pick an existing one).
  2. Enable the Google Drive API (APIs & Services → Library → search "Drive").
  3. Configure the OAuth consent screen as "External", add your Google account as a test user.
  4. Go to Credentials → Create OAuth Client ID. Type: Web application.
  5. Under Authorized JavaScript origins, add the URL where this page lives (e.g. https://yourname.github.io).
  6. Copy the Client ID and paste it below. It saves locally — never sent anywhere.
